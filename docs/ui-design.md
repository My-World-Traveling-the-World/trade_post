已按效果图迭代过两轮。效果图：`docs/ui-mock-3.png`（3× 放大）。

## 一、素材与用法

| 素材 | 尺寸 | 用法 |
|---|---|---|
| `interfaces/villager/base_trades.png` | 102×166 | 只取 4px 木框/倒角/高光；内部烘焙的假文字抹平，重画 7 条分隔线 → `assets/tradepost/textures/gui/market_list.png` |
| `interfaces/villager/base_counter.png` | 173×166 | 原图直接放右半：上半是柜台画（木桶/天平/村民/账本），下半留给详情板 |
| `sprites/container/slot.png` | 18×18 | 行内槽位；**要压暗**（叠 `#2E211A` α168）否则浅色纸槽太抢眼 |
| `sprites/container/villager/scroller.png` | 6×27 | 列表滚动条（内容超 7 行时） |
| `widget/button.png` | 200×20 | 主按钮三态（裁到 158 宽或九宫格拼） |

调色板：底 `#3F240E`、木 `#845937`、亮木 `#9B7244`、高光 `#C19759`、米边 `#AD8854`、分隔 `#6D4327`。

> 这 5 张 PNG 在 522 个 jar 里零引用（class + json 全扫过），只能当皮肤。

## 二、窗口

- **275×166**（左 102 列表 + 右 173 柜台），1:1 像素，屏幕居中。
- 页签只有 **买 / 卖** 两个（28×13，浮在窗口上方 6px 处）；「宝」先不做，代码里保留开关 `relicsEnabled`，开回来时再加第三个页签。
- 选中页签：填充 `#845937` + 顶边高光 `#C19759`；未选中：填充 `#3F240E`、边 `#5B341E`、字 `#9B7244`。

## 三、列表（左 102 宽）

- **7 行 × 20px**，首行顶 `y=19`（19/39/59/79/99/119/139）。
- 行分隔：每行上方 1px `#6D4327`。
- 行内（相对行顶 y）：
  - 槽位 18×18 @ `x=5, y+1`（slot sprite 压暗 + 1px `#6D4327` 边）
  - 物品图标 16×16 @ `x=6, y+2`（`method_51427` 画真实 ItemStack）
  - 名称 @ `x=27, y+13`，金色白 `#F2E6D8`，截断到 50px
  - 价格右对齐到 `x=88`，`#C19759` 小号
- 超过 7 行：滚动条 6 宽放 `x=89..94`，滑块用 `container/villager/scroller`。

## 五、MarketScreen.java 落点

1. 背景两段：`method_25302` blit 自己的 `tradepost:textures/gui/market_list.png`；右半 blit `minecraft:textures/gui/interfaces/villager/base_counter.png`（资源包没开时降级到原版 `textures/gui/container/villager.png`）。
2. 行：`method_52706(Identifier.of("minecraft","container/slot"), …)` + `method_51427(stack,x,y)`。
3. 详情/按钮：`method_25294` 填充 + 调色板颜色；可选 `method_52706` 用包里 button sprite。
4. payload / 份数 / 零头 / 库存 / 秘宝开关逻辑不动，只换渲染层。
