# 现实世界的定价公式（带系数、带算例）

> 姊妹篇：`PRICING_RESEARCH.md`（模型清单与现状诊断）。本文只放**能直接抄的公式**。
> 本机无外网，文献只记名；所有算例都是拿本项目的 `values.json` 与现有参数算的。

## 0. 先说一个反直觉的事实

真公式的**形状**可以直接借，**系数**抄过来会完全没手感。
以 Almgren 的平方根定律为例，真实股市里 σ≈2%/天、单笔委托只占日成交量千分之几，
算出来的冲击是 0.1%~0.5%；而我们现在一条库存曲线就能把价压掉 45%。
所以正确做法是：**保留曲线的函数形式，重新标定系数**（本文每条都给标定方法）。

## 1. Lerner 加成：毛利由弹性决定（这条最该先抄）

```
(P − MC) / P = 1 / |ε|        ⇒   P = MC / (1 − 1/|ε|)
```

- P 售价、MC 边际成本（我们的 `base`）、ε 需求价格弹性。
- 现实零售毛利率（= 1/ε 的实证版）：食品杂货 25~30%、日用 20~25%、消费电子 10~20%、
  服饰 40~50%、珠宝/奢侈品 50~70%。
- **映射到我们**：`base` 当 MC，按品类给毛利 m：食物 25%、材料 15%、工具 35%、装备 45%、
  奢侈品 60%。卖价 = base × (1+m) × 行情系数。
- 好处：毛利**按品类分层**，而不是现在这样全品类恒定 9%。
- 坑：Lerner 是垄断者最优，ε<1 时理论上能无限加价——ε 要夹到 ≥1.2。

## 2. 等弹性需求：以量补价的**唯一**严格形式

```
反需求：P(q) = P0 · (q / D)^(−1/ε)          // q ≤ D 时取 P0，超出 D 才开始衰减
总收入：R(q) = P0 · D^(1/ε) · q^(1 − 1/ε)
```

关键指数是 `1 − 1/ε`：ε=1.5 → 0.333；ε=2 → 0.5；ε=3 → 0.667。
**收入随量次线性增长**——这就是「便宜货靠量、但堆量堆不出暴富」的数学来源。

| ε | 卖 4 倍的量 | 16 倍 | 64 倍 |
|---|---|---|---|
| 1.2（主食） | ×1.26 | ×1.59 | ×2.00 |
| 1.5（材料） | ×1.59 | ×2.52 | ×4.00 |
| 2.0（工具） | ×2.00 | ×4.00 | ×8.00 |
| 3.0（奢侈品） | ×2.52 | ×6.35 | ×16.0 |

算例（用真实 base）：

| 货 | base | D（日深度） | 卖 D 件 | 卖 4D 件 | 若按现价直算 4D |
|---|---|---|---|---|---|
| 面包 | 0.35 | 256 | 89.6 | 142 | 358 |
| 铁锭 | 2.00 | 64 | 128 | 204 | 512 |
| 下界合金锭 | 180 | 4 | 720 | 1148 | 2880 |

⇒ 便宜货**能靠量赚**（面包 4 倍量 +59% 收入），贵货**堆量没用**（多卖 3 倍只多 59%，还得砸价）。
这正是「粮食靠周转、珠宝靠单件」的数学版本。

## 3. 平方根冲击（Almgren 2005 的实证式）

```
永久冲击  I = γ · σ · (X / V)^0.6        γ ≈ 0.314（论文拟合值）
临时冲击  J = η · σ · (X / (V·T))^0.6    η ≈ 0.142
```

- X 本次卖出件数、V 日成交量（= 我们的 D）、σ 日波动率、T 参与时长占比。
- 真实系数代进去几乎没冲击（见第 0 节），要**重标定**：想让「卖满 D 件时砸价 20%」：
  `γ_game = 0.20`（因为 (D/D)^0.6 = 1）。于是：

| 卖的量 | 0.25D | 0.5D | 1D | 2D | 4D | 8D |
|---|---|---|---|---|---|---|
| 砸价 | 8.7% | 13.2% | 20% | 30.3% | 45.9% | 69.6% |

- 这就是「同一种货越卖越便宜」的正确曲线：**前几件几乎不疼，越往后越疼**，
  而且永远到不了 100%（现在的线性曲线会撞到 0.55 地板就停）。
- 我们缺的就是这个「疼得越来越快」的形状：现在 `buyImpact / sellImpact` 是线性的，
  「再卖一摞」和「第一摞」掉价一样多。

## 4. 库存定价的严格版：常数乘积（AMM）

```
池子：E 颗绿宝石、G 件货，现货价 = E / G
买 q 件要付：ΔE = E · q / (G + q)        均价 = E / (G + q)
卖 q 件得到：ΔG = G · q / (E + q)        均价 = G / (E + q)
```

算例（E=3000、G=1000，现货 3 颗/件）：买 1 件付 3.00、10 件均价 2.97、100 件 2.73、500 件 2.00。

- 好处：**单价永远 >0、积分精确**（不会出现「卖了 400 件反而少赚」），买卖两侧自动相反
  （买贵卖贱，天然没有套利）。比现在的 `1 − slope·(ratio−0.5)` 稳。
- 落地：村子的 E 用 `walletCap`、G 用 `Stock.cap(base)` 换算到件数。

## 5. 价差 = 固定项 + 比例项（Stoll 1978 / Ho-Stoll 1981 / Avellaneda-Stoikov 2008）

```
做市商报价（A-S 2008）：
  保留价  r = s − q·γ·σ²·(T−t)                 // q 库存，γ 风险厌恶
  半价差  δ = ½·γ·σ²·(T−t) + (1/γ)·ln(1 + γ/κ)  // κ 下单强度
```

代入 γ=0.1、κ=1.5、T=1 天，看价差**占价格的比例**随价格怎么变：

| 价格（颗） | σ（颗） | 价差（颗） | 价差占比 |
|---|---|---|---|
| 0.35 | 0.10 | 1.29 | **369%** |
| 2.0 | 0.40 | 1.31 | **65%** |
| 24.0 | 4.0 | 2.89 | **12%** |
| 180 | 25 | 63.8 | 35% |

- 结论：价差里有一块**与价格无关的固定成本**（`(1/γ)ln(1+γ/κ)`），所以便宜货的价差占比天然巨大。
- 这条恰好解释了你的体感：便宜货「赚不到钱」不是我们算错了，而是**固定成本摊不开**。
  现实里的解法是**摊**（一船一船地运），不是把比例调大。
- 落地：`净收入 = P·q − F`，F 按每笔/每行每天首笔收；或折进价差：`收价 = 卖价 − F/q`。

## 6. 引力模型（村与村之间该有多少货流）

```
T_ij = G · (M_i^a · M_j^b) / d_ij^β        a,b ≈ 1，β ≈ 0.7 ~ 1.5（实证多用 1）
```

- T 贸易量、M 经济规模（村财富）、d 距离（格）。
- 用途：决定「两个村值不值得跑」、风声往哪传、修路后 β 要不要降。
- 现状其实隐含 β：`roadFactor()` 与 `areaSpread`，但没写成距离的幂函数。

## 7. 一价定律 + 运输成本套利带

```
|P_i − P_j| ≤ t · d_ij            // t = 每格运费
```

- 我们的 `LOCAL_SPREAD = 0.75` 其实就是「运费 = 25% 的价」，只是写成了常数比例。
- 改成 `收价 ≤ 卖价 − t·d` 后，远村套利自动更难、近村更容易——比全局常数更像跑商。

## 8. 粘性价格（菜单成本 / Calvo）

```
部分调整：P_t = P_{t−1} + λ·(P* − P_{t−1})        λ ≈ 0.1 ~ 0.3 / 天
Calvo：每期只有 (1−θ) 比例的商品重定价，θ ≈ 0.6 ~ 0.75
```

- 用处：面板上的价钱别每笔成交都抖（现在箭头「一天只记一次底」就是这条的粗糙版）。
- λ=0.2 时，价格偏离目标后**半衰期约 3 天**，玩家能看见「这个村慢慢涨价」。

## 9. 规模经济运费（固定费的现实出处）

```
单位运费 = F / q + c          // F 起运费（订舱、装卸、报关），c 每件变动成本
```

- 现实数字：整箱 $2000/FEU 装 20 吨 → 0.1 美元/公斤；拼箱 0.5~1 美元/公斤。
  同样的货，量差 5~10 倍运费——这是批发/零售价差的物理来源。
- 落地：车马费就该是 `F/q` 这个形状，而不是每件固定抽成。

## 10. 两条可以当体检指标的

```
存货周转（GMROI）：利润 = 毛利率 × 周转次数
经济订货量：Q* = sqrt(2·D·S / H)      // D 年需求、S 每次订货成本、H 单位持有成本
```

## 11. 我们自己的数据也符合幂律

把 `values.json` 的 233 条手写价按 Pareto 拟合（xmin=1，尾 76 条）：**α ≈ 1.67**。
⇒「绝大多数货很便宜、极少数极贵」不是设错了，是价格表本身的性质。
所以给便宜货开「量」的口子（第 2、3 条）方向是对的，而不是把它们整体提价。

## 12. 如果只挑三条拼成一个模型

```
卖价（一批 q 件）：
  P0   = base × (1 + m_category) × 行情系数        // 第 1 条：Lerner 毛利
  D    = D0 × (村财富 / base)^0.5                  // 深度：便宜货深、贵货浅
  P(q) = P0 · max(1, q/D)^(−1/ε)                   // 第 2 条：等弹性，超深度才衰减
  收款 = P(q) · q − F                              // 第 9 条：固定运费

买价（村子卖给你，q 件）：
  第 4 条常数乘积，池子 E/G 由村财富与库存换算；
  再保证 卖价 ≤ 买价 × 0.75（现在的封顶留着当保险丝）。
```

每个参数都有现实对应（m←零售毛利、ε←品类弹性、D←市场深度、F←起运费），而且**互相不打架**：
便宜货靠 D 大 + ε 小赚量，贵货靠 m 高但 D 小、超量立刻衰减。

## 13. 标定清单（真要动手时按这个顺序调）

## 15. 算例（用真实 base 与真实产量假设，2026-11-13 实算）

参数（只为演示，不是提案）：品类毛利 m＝食物 25% / 材料 15% / 装备 45% / 奢侈品 60%；
ε＝食物 1.2 / 材料 1.5 / 装备 2.5 / 奢侈品 3.0；深度 `D = 90.5 / √base`（让铁锭 base=2 时 D=64）；
固定费 F＝2 颗/笔。

### 15.1 现状：毛利恒 9%，差在「每格价值」

| 货 | base | 一组 64 件价值 | 一组毛利（9%） | 一背包 36 格毛利 |
|---|---|---|---|---|
| 小麦 | 0.12 | 7.7 | 0.7 | 25 |
| 面包 | 0.35 | 22.4 | 2.0 | 72 |
| 铁锭 | 2.00 | 128 | 11.5 | 414 |
| 钻石 | 24.0 | 1536 | 138 | 4977 |
| 下界合金锭 | 180 | 11520 | 1037 | 37325 |

⇒ 同样「装满背包」，小麦 25 颗、下界合金 37325 颗，**差 1500 倍**。这是「背一包便宜货卖不出钱」的数学来源。

### 15.2 换成「每小时能产出多少」，差距只剩 2.4 倍

假设（正常游戏速度）：小麦 1200 件/时、面包 400 个/时、铁锭 64 块/时、钻石 6 颗/时、下界合金锭 2 块/时。

| 货 | 每小时产量 | 现状利润/小时（9%） |
|---|---|---|
| 小麦 | 1200 | 13 |
| 面包 | 400 | 13 |
| 铁锭 | 64 | 12 |
| 钻石 | 6 | 13 |
| 下界合金锭 | 2 | 32 |

⇒ **单位时间的赚钱速度其实差不多**（12~32）。所以「便宜货难赚钱」的痛点是**单趟/单次交互回报太低**（摩擦），
不是价格公式——这也是「整摞卖、自动认行、连续成交」比调价更立竿见影的原因。

### 15.3 Lerner 品类毛利：便宜货 ×2.8，贵货 ×6.7（注意：会更悬殊）

| 货 | base | 品类 | m | 每件利润（新/旧） | 一组 64（新/旧） | 倍数 |
|---|---|---|---|---|---|---|
| 小麦 | 0.12 | 食物 | 25% | 0.03 / 0.01 | 1.9 / 0.7 | 2.8× |
| 面包 | 0.35 | 食物 | 25% | 0.09 / 0.03 | 5.6 / 2.0 | 2.8× |
| 铁锭 | 2.00 | 材料 | 15% | 0.30 / 0.18 | 19.2 / 11.5 | 1.7× |
| 钻石 | 24.0 | 材料 | 15% | 3.60 / 2.16 | 230 / 138 | 1.7× |
| 下界合金锭 | 180 | 奢侈品 | 60% | 108 / 16.2 | 6912 / 1037 | 6.7× |

⇒ **只加品类毛利会把差距拉得更大**（1500× → 3600×）。它必须和「深度/固定费」一起上；
现实里奢侈品的 60% 毛利是靠「一年只周转几次」换来的。

### 15.4 深度 + 等弹性：贵货一次卖不了几件

| 货 | base | 日深度 D | 卖 1D 的价 | 2D | 5D | 10D |
|---|---|---|---|---|---|---|
| 小麦 | 0.12 | 261 | 0.15 | 0.08 | 0.04 | 0.02 |
| 面包 | 0.35 | 153 | 0.44 | 0.25 | 0.11 | 0.06 |
| 铁锭 | 2.00 | 64 | 2.30 | 1.45 | 0.79 | 0.50 |
| 钻石 | 24.0 | 18 | 27.6 | 17.4 | 9.4 | 6.0 |
| 下界合金锭 | 180 | 7 | 288 | 229 | 168 | 134 |

⇒ 一个村一天能原价吃下 **261 份小麦 / 153 个面包 / 64 块铁 / 18 颗钻石 / 7 块下界合金锭**。
贵货不是「不值钱」，是「卖不动」——想多卖就得跑更多村。

### 15.8 结论（按重要性）

1. **先降摩擦**（已做大半）：单趟收益低主要是「背一包便宜货只能卖几趟、每趟几十颗」，
   整摞卖/自动认行/连续成交就是在补这个洞。
2. **要不要动价，取决于便宜货靠什么赚**：靠量（15.4 的深度做大）就够；靠毛利（15.3）会把差距拉更大。
3. **贵货必须「卖不动」**（15.4）才不会变成唯一解；单靠毛利分层不行。
